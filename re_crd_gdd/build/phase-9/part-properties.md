## Field Guide

### Common header (first 24 bytes / 12 words)

| Word | Offset | Name | Description |
|------|--------|------|-------------|
| 0 | 0 | mass | mass/density (relative scale) |
| 1 | 2 | unk_2 | category-specific property |
| 2 | 4 | property_q8 | property in Q8.8 (COR for balls, friction for walls) |
| 3 | 6 | unk_6 | category-specific property |
| 4 | 8 | pad_8 | always 0 |
| 5 | 10 | dim_w1 | dimension 1 width |
| 6 | 12 | dim_h1 | dimension 1 height |
| 7 | 14 | dim_w2 | dimension 2 width |
| 8 | 16 | dim_h2 | dimension 2 height |
| 9 | 18 | bitmap_w | bitmap frame width |
| 10 | 20 | bitmap_h | bitmap frame height |

### Category-specific variations

- **Balls** (80b format): w2 = COR (Q8.8 fixed-point). Super ball = 512 (COR=2.0), bowling = 128 (COR=0.5).
- **Walls** (28b format): w2 = friction/material code (not COR). Sand=48, Log=96, Grass=128, Caution=512, Standard=1024.
- **Scenery** (28b format, mass=0): w9-w10 = bitmap size. No physics fields.
- **Inclines**: w6=0 (flat top), w7=64, w8=0 (different AABB from walls).
